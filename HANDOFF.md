# HANDOFF — refhealth-dbt-healthcare-checks

## Fast Orientation

This is an open-source dbt package repository containing reusable generic test macros for healthcare data warehouses.

Key files:
- `dbt_project.yml` — package manifest and config.
- `macros/` — test macros returning failing rows per dbt generic test standards.
- `README.md` — public documentation and usage examples.
- `LICENSE` — MIT License.
